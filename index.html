Read it and pull out the name, a short description, how many it serves, prep and cook minutes, the ingredients (amount, unit, item) and the steps. If I ask for only part of a recipe, take only that part. Use what the source actually says; leave anything it doesn't state as None.

Then run this Python and give me the link it prints:

import base64, json, uuid, zlib

recipe = {
    "name": "Coleslaw",
    "description": "",
    "servings": 4,
    "prepMinutes": None,
    "cookMinutes": None,
    "ingredients": [
        {"amount": 250, "unit": "g", "item": "white cabbage, finely shredded"},
        {"amount": 3, "unit": "tbsp", "item": "light mayonnaise"},
        {"amount": None, "unit": "", "item": "salt and pepper, to taste"},
    ],
    "steps": ["Mix everything together in a bowl."],
    "tags": ["side"],
}

payload = {"v": 1, "r": {"id": str(uuid.uuid4()), "image": "", **recipe}}
data = json.dumps(payload, separators=(",", ":"), ensure_ascii=False).encode()
z = zlib.compressobj(9, zlib.DEFLATED, -15)
blob = base64.b64encode(z.compress(data) + z.flush()).decode()
print("https://malfernion.github.io/Recipe-friend/#add=1."
      + blob.replace("+", "-").replace("/", "_").rstrip("="))

Replace the example recipe with mine. The app is strict about these, and quietly ignores a recipe that breaks one:

- a name, at least one ingredient and at least one step are all required
- amount is a positive number, or None for "to taste" — never 0, and halves are 0.5, never "1/2"
- unit is "" when there isn't one. g, kg, oz, lb, ml, l, cup, fl oz, tsp and tbsp get converted to whatever units the reader prefers; anything else (clove, pinch, can) is kept as written
- leave "image" as it is — photos can't travel in a link

Give me the link exactly as the code printed it. If you can't run code, say so rather than guessing a link.
