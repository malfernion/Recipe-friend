      Sharing

          No invite links are live for this book.

          An invite link lets one person join this book, and expires after 48 hours. Anyone who joins can add, edit and delete its recipes, so treat a link like a key: send it to one person, and revoke it if it goes astray.

          Measurement preferences

          Recipes are stored exactly as they were entered; this only changes how amounts are shown to you. Everyone sharing a book can keep their own setting. Teaspoons and tablespoons stay as they are, and units we don't recognise ("cloves", "pinch", "can") are never converted.

          Get help from AI

          Copy this into ChatGPT, Gemini, Claude or similar, then send it the recipe — a link, a photo of a cookbook page, or typed-out text. It replies with a block of JSON and a link back to the paste box; either follow that link or use Paste a recipe below. You get to check and edit the recipe before it is saved.

          I want to add a recipe to Recipe Friend. I'll give you the recipe next — a link, a photo, or just text.

Read it and reply with only a JSON object in this exact shape, in a code block, with nothing else around it:

{
  "name": "Coleslaw",
  "description": "A quick creamy slaw.",
  "servings": 4,
  "prepMinutes": 10,
  "cookMinutes": null,
  "ingredients": [
    {"amount": 250, "unit": "g", "item": "white cabbage, finely shredded"},
    {"amount": 3, "unit": "tbsp", "item": "light mayonnaise"},
    {"amount": null, "unit": "", "item": "salt and pepper, to taste"}
  ],
  "steps": ["Mix everything together in a bowl."],
  "tags": ["side"]
}

Rules the app is strict about — it will reject a recipe that breaks one:

- a name, at least one ingredient and at least one step are all required
- amount is a number, or null for "to taste" — never 0, and halves are 0.5, never "1/2"
- unit is "" when there isn't one. g, kg, oz, lb, ml, l, cup, fl oz, tsp and tbsp get converted to whatever units the reader prefers; anything else (clove, pinch, can) is kept as written
- use what the source says, and leave anything it doesn't state as null

If I ask for only part of a recipe, include only that part.

After the JSON, give me this link on its own line so I can click straight through to the box I paste it into:

https://malfernion.github.io/Recipe-friend/#paste

          Paste a recipe

          Paste the JSON an assistant gave you — code fences and all, if it used them. A share link works here too. Nothing is saved until you have looked it over on the next screen.
